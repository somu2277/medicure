# MediCare — Dataset Sources

The MediCare project uses structured placeholder and synthetic datasets inspired by real-world taxonomy for demonstration and structural testing.

## Categories & Subcategories
- **Source:** Generated structurally based on standard eCommerce pharmacy catalogs.
- **License:** Open (Synthetic)
- **Usage:** Used to populate the Mega Menu and Category APIs.

## Health Concerns
- **Source:** Common medical search patterns (e.g., Diabetes, Fever, Skin Care).
- **License:** Open (Synthetic)
- **Usage:** Used to filter products by `healthConcernIds`.

## Product Metadata (Seed Data)
- **Source:** Manually structured synthetic products representing different product types (Medicine, Supplements, Devices). 
- **License:** Synthetic / Demo
- **Usage:** Used to test Cart, Checkout, Inventory, and Mappings.

*Note: No automated scraping was performed to generate this database.*
